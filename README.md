# 分散と標準偏差の体験的理解アプリ

このWebアプリケーションは、分散と標準偏差の概念を体験的に学習するためのStreamlitアプリケーションです。

## 機能概要

### 📊 アプリケーションの特徴
- **ステップバイステップの学習**: 分散と標準偏差の計算プロセスを段階的に理解
- **視覚的な理解**: Plotlyを使用したインタラクティブなグラフとチャート
- **実データとデモデータ**: CSVファイルのアップロードまたはデモデータの使用
- **比較分析**: 複数のデータセットのばらつきを視覚的に比較

### 🎯 学習内容
1. **データの確認と平均値の計算**
   - データの分布をヒストグラムで表示
   - 平均値の計算と視覚化

2. **分散の計算と理解**
   - 偏差（各データ - 平均値）の計算
   - 偏差の2乗の意味と計算
   - 分散の定義と計算過程

3. **標準偏差の計算と活用**
   - 標準偏差の定義（分散の平方根）
   - ±1標準偏差の範囲の視覚化
   - データのばらつきの実用的な意味

4. **まとめと応用**
   - データセット間の比較分析
   - 実用的な応用例の紹介

## 🚀 使用方法

### 1. 必要なパッケージのインストール
```bash
pip install -r requirements.txt
```

### 2. アプリケーションの起動
```bash
streamlit run app.py
```

### 3. データの準備
以下のいずれかの方法でデータを使用できます：

#### デモデータを使用する場合
- アプリ画面で「デモデータを使用する」にチェック
- 平均値は同じだが分散が異なる2つのテストデータが自動で読み込まれます

#### 独自のCSVファイルを使用する場合
CSVファイルは以下の形式で準備してください：
```csv
データ名,値
テストA,68
テストA,70
テストB,85
テストB,90
```

## 📊 デモデータについて

アプリに含まれるデモデータは以下の特徴を持っています：
- **テストA**: 平均77点、標準偏差が小さい（成績が平均付近に集中）
- **テストB**: 平均77.5点、標準偏差が大きい（成績のばらつきが大きい）

この例により、平均値が似ていても分散・標準偏差によってデータの特徴が大きく異なることを学習できます。

## 🎓 教育的価値

このアプリケーションは以下の学習目標をサポートします：
- 統計の基本概念（平均値、分散、標準偏差）の理解
- 数式だけでなく視覚的・直感的な理解の促進
- 実データを使った体験的学習
- 統計指標の実用的な応用の理解
